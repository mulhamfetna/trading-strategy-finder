## 3. Full logic breakdown — the end-to-end decision pipeline

Each 4-hour bar flows through this pipeline. Steps 1–6 run inside the engine; step 7 is the causal
post-processing overlay.

```
 ┌── for each new 4h bar ───────────────────────────────────────────────┐
 │ 1. SIGNAL    Stage-1 box rule on the just-closed bar → long/short/hold │
 │ 2. GATE      HAR-RV vol forecast for this bar > 60th pct? → SKIP (hold) │
 │ 3. ENTRY     if long/short and not gated and no open trade → open @ close│
 │ 4. STOPS     place tight lines: SL_hard ±25, SL_soft ±20, TP ±40        │
 │ 5. EXIT WALK 1-min bars of this window: hard TP/SL on touch,            │
 │              soft SL on 2 consecutive 1-min closes past the soft line   │
 │ 6. RECORD    closed trade: entry/exit, direction, reason, P/L           │
 └──────────────────────────────────────────────────────────────────────┘
                              │  (chronological closed-trade stream)
                              ▼
 7. CIRCUIT-BREAKER overlay (causal): walk trades in order; if running
    drawdown ≥ $2,500 → LOCK (skip new entries) for 20 trades → re-probe.
```

**Step-by-step (technical → baby):**
1. **Signal** — the verified box logic decides long/short/hold from the just-closed bar.
   *Baby:* "the original recipe says buy, sell, or wait."
2. **Volatility gate** — we forecast this bar's volatility (HAR-RV, the WS-A winner). If it's in
   the **top 40%** (above the 60th percentile set on 2025), we **don't trade** — those are the
   wild, dangerous bars. *Baby:* "if the sea looks stormy, stay in the harbour."
3. **Entry** — otherwise open one contract at the bar's open price.
4. **Tight stops** — the safety net sits only **25 points** away (≈$500) and the target **40
   points** away (≈$800). *Baby:* "small seatbelt distance — we never lose much on one trade."
5. **Exit walk** — the unchanged dual soft/hard exit model decides the fill using 1-min bars.
6. **Record** the closed trade.
7. **Circuit-breaker** — a risk supervisor sitting above the strategy: it adds up results in order,
   and the moment the running loss from the high-water mark reaches **$2,500**, it **stops taking
   new trades** for the next 20 trades, then cautiously tries again (resetting its high-water mark).
   *Baby:* "if we start bleeding, we put the gloves down for a while, then test the water again."

## 4. The circuit-breaker — state machine

![State diagram](../plots/winning_system/state_diagram.png)

Two states, fully causal (the decision for a trade uses only earlier trades):
- **TRADING** → **LOCKED** when *running drawdown ≥ $2,500*.
- **LOCKED** → **TRADING** after *20 skipped trades* (cooldown), and the drawdown peak **resets to
  the current equity** so it measures a fresh decline from the resume point (otherwise it could
  stay locked forever).
- Self-loops: a win/small-loss keeps it TRADING; an unfinished cooldown keeps it LOCKED.

Because the per-trade loss is capped at ~$500, the breaker can only *overshoot* its $2,500 limit by
about one trade — which is why the **actual** max drawdown ($3,695) lands cleanly under the $5,000
target. (A 100-point stop would overshoot by up to $2,000, which is why the tight stop matters.)

## 7. Why it works (mechanism)
Three independent risk reducers compound:
1. **The gate removes the worst bars** before they can hurt (volatility is predictable — WS-A).
2. **Tight stops cap each loss at ~$500**, eliminating the fat left tail and shrinking loss clusters.
3. **The breaker halts during a bleed**, so even a run of losses can't compound into a deep hole.
Together they convert a boom-bust equity curve (+$45k → −$13k) into a smooth grind (+$20k, $3.7k
worst dip). The cost is the explosive upside: in a strong trend the tight stops + gate **leave money
on the table** (2025 +$12.6k vs the baseline's +$41.7k peak path).

## 8. Honest caveats (read before trusting)
1. **n = 1 regime.** The gate percentile (60), stop sizes (20/25/40), and breaker (`$2,500` / 20)
   were all chosen on the *same* 2025–2026 data — **in-sample on one regime**. These dollars show
   what the *mechanism* can do, not a validated forward return. Out-of-sample (more instruments /
   years → Workstream F) is required.
2. **It trades smoothness for upside.** By design it underperforms the baseline in strong trends
   (see the green vs red gap in mid-2025). If the goal were max P/L regardless of drawdown, this is
   *not* the config.
3. **Win rate fell to 44.6%** (from 64%). The edge is now "small capped losses + avoid bad bars +
   halt on bleed", not a high hit-rate — a different strategy character to discuss with the team.
4. **The breaker is a research overlay**, computed causally on the trade stream; to run live it
   must be implemented as an equity-stop in execution.
5. **The stop parameters differ from the team-verified 80/100/50** — this is a parameter choice
   (inputs), not an engine-logic change; the engine itself is the untouched, parity-tested clone
   (see `notes/42`). A param-faithful alternative (`G60 + breaker`, keeps 80/100/50) gives
   +$11,470 at $4,810 maxDD.
6. **The strict "DD ≤ 10% of P/L" target is not met** (18%); it's infeasible on this data — see
   `notes/43`.
