## 🔧 WHAT I GOT WRONG TODAY (and caught)

Kept honest because the mistakes are the most useful part of the record:

1. **Killed a healthy run** — misread a running error counter (44) against the code's 5-line print cap and
   thought the sample was being eaten. Both runs had identical, expected errors.
2. **A results file said the opposite of the result** — committed `17y_pattern.txt` with an inverted power
   label (power computed against the *observed* effect is circular).
3. **A cache that never hit** — validated by date-span, which could never pass; 945 API calls re-ran every
   time while the log printed "rebuilding" as if normal.
4. **A sweep detector that was true by construction** — searched for "recovery" starting on the very bar
   that triggered the stop → 97.4% sweeps, median 0 seconds. The zero was the tell.
5. **A verdict that tested the wrong thing** — coded criterion (B) as "is it negative?" when I had
   *declared* "is it indistinguishable from zero?" — it would have retracted a correct report on noise.
6. **Nearly hand-typed a 17-row table from memory** — caught and replaced with the real run output.

**The through-line:** every safeguard that saved me was declared *before* the run — power against a
pre-set effect, a dumb control, a noise check, a written kill criterion. → [[feedback_dumb_control_and_noise]].
