# `frontend/src/services/chart_theme.ts`

One export, `CHART_THEME`, a frozen object literal. No functions.

Adding a colour: add it both here AND in `tailwind.config.js` under the `tv` palette so the chart canvas and the surrounding Vue UI stay visually consistent.

## Colour tokens

| Token | Hex | Where it appears |
|---|---|---|
| `bg` | `#131722` | Chart background |
| `text` | `#d1d4dc` | Axis labels |
| `border` | `#363a45` | Grid lines + axis borders |
| `muted` | `#787b86` | Empty-state placeholder text, tooltip date colour |
| `bull` | `#00c853` | Up bar / long entry arrow / winning exit marker |
| `bear` | `#ff5252` | Down bar / short entry arrow / losing exit marker |
| `bullTinted` | `#00c85344` | Volume bar on an up close (~27% alpha) |
| `bearTinted` | `#ff525244` | Volume bar on a down close |
| `bullThreshold` | `#00c85388` | RSI 30 line (~53% alpha) |
| `bearThreshold` | `#ff525288` | RSI 70 line |
| `emaFast` | `#f7931a` | Fast EMA overlay, also the colour of the "EMA hidden" warning chip |
| `emaSlow` | `#2962ff` | Slow EMA overlay |
| `rsi` | `#9c27b0` | RSI line in its own pane |

These are the ONLY hex literals the chart ever uses. ChartPane's `<style scoped>` block doesn't repeat them — it sources them via CSS custom properties (`--chart-muted`, `--chart-ema-fast`) populated from `CHART_THEME` on the root element.

Box rectangle colours are NOT in this file — each `BoxRect` carries its own `fill_color` / `border_color` strings, generated by `_LEVEL_COLORS` in [[src_strategy_box_lookup]]. Different concern (per-level palette), kept where it lives so the backend has a single source for it too.
